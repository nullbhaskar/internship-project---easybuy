## 🌟 Overview

**EasyBuy** is a modern, high-performance e-commerce mobile application designed to redefine the shopping experience. Built for a university internship project, it integrates cutting-edge AI technologies, real-time database management, and a meticulously crafted user interface to deliver a seamless shopping journey.

From dynamic AI-powered pricing to dual intelligent shopping assistants, EasyBuy represents the future of mobile retail.

## ✨ Key Features

- **🤖 Dual AI Assistants:** 
  - **Voice Assistant:** Speak to the app to search for products hands-free.
  - **Chat Assistant:** A context-aware text AI that helps users find products, track orders, and answer queries.
- **⚡ Smart Dynamic Pricing:** Real-time, AI-driven intelligent pricing algorithms that adjust based on demand and user behavior.
- **🔐 Secure Authentication:** Full email/password registration with real-time Email OTP verification, powered by Firebase Auth.
- **🛒 Seamless Checkout:** Integrated cart management with smooth micro-animations, haptic feedback, and guest checkout support.
- **📊 Admin Dashboard:** A powerful hidden admin panel to manage inventory, update order statuses (Pending, Processing, Shipped, Delivered), and view revenue analytics via beautiful SVG curved graphs.
- **🎨 Premium UI/UX:** Glassmorphism, smooth skeleton loaders, interactive swipe gestures, and responsive layouts.

## 🛠 Tech Stack

- **Frontend:** React Native, Expo, React Navigation, Expo Router
- **Backend & Database:** Firebase (Firestore, Auth, Storage)
- **AI Integration:** Groq API (LLaMA 3) for lightning-fast natural language processing
- **Styling:** Custom CSS styling, React Native Animated API, Expo Haptics

## 🚀 Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn
- Expo Go app on your iOS/Android device (or a local emulator)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nullbhaskar/internship-project---easybuy.git
   cd "internship-project---easybuy/easybuy"
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npx expo start
   ```

4. **Run on your device:**
   - Scan the QR code shown in the terminal using the **Expo Go** app on your phone.
   - Or press `a` to open on an Android emulator, or `i` for an iOS simulator.
